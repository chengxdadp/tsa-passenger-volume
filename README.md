## 使用方法

```bash
# 日常更新（抓取最新数据 + 刷新图表和 README）
python script/update.py

# 补录历史年份
python script/update.py --year 2025

# 仅重新生成图表（不联网）
python script/update.py --charts-only
```

Windows 用户可直接双击 `update_tsa_data.bat`。

详细文档见 [script/README.md](script/README.md)。
